## 🎨 Design & Tecnologias

Identidade visual de "engenharia de automação": painel escuro de monitoramento onde o verde é cor de status — sistema operacional, disponível.

| Recurso | Detalhe |
|---|---|
| Fontes | Space Grotesk (títulos) + Inter (texto) + JetBrains Mono (labels, datas e terminal) via Google Fonts |
| Paleta | Navy profundo (#0a1220) com grid de blueprint ao fundo, verde-sinal (#3ddc97) como acento de status e ciano (#7fd4f0) como acento secundário |
| Assinatura | Terminal animado no hero que digita em loop o fluxo processo manual → SAP/ServiceNow → IA → Power BI → ✓ concluído |
| Ticker | Faixa rolante com as tecnologias do LinkedIn (Python, JavaScript, SQL, Oracle, Power BI, Streamlit, Power Automate, n8n, APIs, Windows Server, AD, Entra ID, ServiceNow, SAP ECC) |
| Layout | CSS Grid e Flexbox responsivos, mobile-first nos breakpoints |
| Linha do tempo | Trajetória profissional em timeline vertical com nó "presente" pulsante |
| Animações | IntersectionObserver com efeito reveal ao rolar; pausa do ticker no hover |
| UX | Botão "voltar ao topo"; formulário de contato abre o cliente de e-mail com a mensagem pronta |
| Acessibilidade | Skip link, foco visível (:focus-visible), prefers-reduced-motion respeitado (terminal renderiza instantâneo, ticker e animações desligam) |

## 🚀 Como Usar

### Abrir localmente

Basta abrir o `index.html` no navegador.

### Rodar com servidor estático (recomendado)

```
# Python
python -m http.server 8080
```

Acesse: http://localhost:8080

### Comando para abrir arquivo direto (opcional)

```
# Windows (PowerShell)
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```
